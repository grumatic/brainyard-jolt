# Agent Instructions

## Project rules

- Decisions are recorded in `docs/decisions/`, and the work keeps to them.
- Every change someone using the workspace could notice adds a line under
  `## Unreleased` in CHANGELOG.md, in the same commit.
- Work on a bead ends committed, with the bead closed: claim the bead before
  working on it, commit its work, then close it.
- This repository opts in to the Team-maintainer profile of the Beads block
  below: an agent commits its own work and closes its beads without being
  asked. It never pushes.
