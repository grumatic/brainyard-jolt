# Provenance

The past failures that comments in the code point to. Specifications are in
`docs/RFCS/` and the deliberate differences from brainyard in
`docs/divergences.md`; neither belongs here. Some guards in the code exist
because of a single earlier failure, and whoever reads the guard needs to find
out what that was. A comment points here as `(provenance P-6)`.

One line each: what broke, how it showed, what guards it now. The full story is
in git history. A number missing from the table is a failure that is not
byj's.
