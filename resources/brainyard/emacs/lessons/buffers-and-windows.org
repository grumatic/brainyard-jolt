#+title: Buffers and windows
#+lesson: buffers-and-windows
#+summary: Switch between open files, see two at once, and close what you do not need.

# A lesson for /emacs coach emacs: (RFC-067 phase 9). Each step names the
# commands that show it done (:COMMANDS:), never keys: the coach looks the
# keys up in the person's own Emacs with emacs$describe, and checks a step
# with emacs$habits. A project's .brainyard/emacs/lessons/ and the person's
# ~/.brainyard/emacs/lessons/ replace a lesson of the same file name.

* Switch to another buffer
:PROPERTIES:
:COMMANDS: switch-to-buffer
:END:
Go to another open buffer by name: every open file is a buffer.

* List the buffers
:PROPERTIES:
:COMMANDS: list-buffers ibuffer
:END:
See every buffer, and open, save or close one from the list.

* Split the window
:PROPERTIES:
:COMMANDS: split-window-below split-window-right
:END:
See two buffers at once, one above the other or side by side.

* Move between windows
:PROPERTIES:
:COMMANDS: other-window
:END:
Go to the other window.

* Back to one window
:PROPERTIES:
:COMMANDS: delete-other-windows delete-window
:END:
Close the other windows, or the one you are in; the buffers stay open.

* Close a buffer
:PROPERTIES:
:COMMANDS: kill-buffer
:END:
Close a buffer you are done with.
