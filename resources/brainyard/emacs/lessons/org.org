#+title: Org basics
#+lesson: org
#+summary: Headings that fold, TODO items, and running a code block in an org file.

# A lesson for /emacs coach emacs: (RFC-067 phase 9). Each step names the
# commands that show it done (:COMMANDS:), never keys: the coach looks the
# keys up in the person's own Emacs with emacs$describe, and checks a step
# with emacs$habits. A project's .brainyard/emacs/lessons/ and the person's
# ~/.brainyard/emacs/lessons/ replace a lesson of the same file name.

* Fold and unfold headings
:PROPERTIES:
:COMMANDS: org-cycle org-shifttab
:END:
Fold a heading's body away and back, or every heading at once.

* Add a heading
:PROPERTIES:
:COMMANDS: org-insert-heading-respect-content org-meta-return
:END:
Start a new heading at the same level.

* Mark TODO and DONE
:PROPERTIES:
:COMMANDS: org-todo
:END:
Cycle a heading through TODO and DONE.

* Run a code block
:PROPERTIES:
:COMMANDS: org-ctrl-c-ctrl-c org-babel-execute-src-block
:END:
Run the src block you are in; its results appear under it.

* Jump between headings
:PROPERTIES:
:COMMANDS: org-next-visible-heading org-previous-visible-heading
:END:
Move from heading to heading.
